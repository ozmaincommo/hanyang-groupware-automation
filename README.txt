그룹웨어 자동화 (한양대 포털 휴가신청/시간외근무/출퇴근처리 자동화)
=====================================================

■ 준비물
  - Google Chrome이 PC에 설치되어 있어야 합니다.
  - Python 3.10 이상 (없으면 https://www.python.org/downloads/ 에서 설치.
    설치 화면에서 "Add Python to PATH"를 꼭 체크하세요.)

■ 처음 받았을 때 (GitHub 등 인터넷에서 다운로드한 경우, 딱 1번만)
  - "run.bat"을 더블클릭했을 때 "스마트 앱 컨트롤이 안전하지 않을 수 있는 파일을
    차단했습니다"라는 창이 뜨면: run.bat 파일에 마우스 오른쪽 클릭 → 속성 →
    하단의 "보안" 항목에서 "차단 해제" 체크박스를 체크 → 확인. 이렇게 하면 이
    파일에 붙은 "인터넷에서 받음" 표시가 지워져서 정상 실행됩니다(스마트 앱
    컨트롤 자체를 끌 필요는 없습니다 — 그건 되돌리기 어려운 조치라 권장하지 않음).
  - 파일이 여러 개라 하나하나 하기 번거로우면, 이 폴더에서 PowerShell을 열고
    다음 명령을 한 번 실행해도 됩니다: Get-ChildItem -Recurse | Unblock-File

■ 실행 방법
  - "run.bat"을 더블클릭하기만 하면 됩니다.
  - 최초 실행이거나 필요한 패키지가 없으면 자동으로 설치부터 합니다
    (인터넷 필요, 1~2분). 이미 설치돼 있으면 인터넷 없이도 바로 실행됩니다.
  - 검은 콘솔 창이 잠깐 떴다가(3초 내) 자동으로 사라지고 컨트롤패널 창만 남습니다.
    아이디/비밀번호(및 필요시 OTP 6자리)를 입력하고 로그인하세요. 자동화 전용
    크롬 창이 뜹니다.
  - 최초 로그인 시 구글 OTP 2차 인증이 뜨면, 뜬 크롬 창에서 직접 인증번호를
    입력해야 합니다(그 이후 당일에는 다시 묻지 않습니다).

■ 개인정보 관련
  - 아이디는 다음 실행 시 편하게 쓸 수 있도록 이 폴더의 credentials.local.json
    파일에 저장됩니다(비밀번호는 절대 저장하지 않습니다).
  - 실행 결과/기록은 이 폴더의 output/ 폴더 안에 쌓입니다. 다른 사람과
    이 폴더를 공유할 때는 output/, credentials.local.json은 제외하고
    전달하는 걸 권장합니다(개인정보가 들어있을 수 있음).

■ 문제가 있을 때
  - 정상적으로 실행되면 콘솔 창은 자동으로 사라집니다. 뭔가 잘못돼서 프로그램이
    아예 안 뜨면, 콘솔 창이 안 사라지고 남아서 에러 메시지를 보여줍니다(영어로
    표시됨, 이 폴더의 error.log 파일에도 저장됨). 문제가 생기면 이 내용을
    캡처해서 알려주세요.
