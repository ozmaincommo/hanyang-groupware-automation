그룹웨어 자동화 (한양대 포털 휴가신청/시간외근무/출퇴근처리 자동화)
=====================================================

■ 준비물
  - Google Chrome이 PC에 설치되어 있어야 합니다.
  - Python 3.10 이상 (없으면 https://www.python.org/downloads/ 에서 설치.
    설치 화면에서 "Add Python to PATH"를 꼭 체크하세요.)

■ 실행 방법
  - "run.bat"을 더블클릭하기만 하면 됩니다.
  - 최초 실행이거나 필요한 패키지가 없으면 자동으로 설치부터 합니다
    (인터넷 필요, 1~2분). 이미 설치돼 있으면 인터넷 없이도 바로 실행됩니다.
  - 컨트롤패널 창이 뜨면, 아이디/비밀번호(및 필요시 OTP 6자리)를 입력하고
    로그인하세요. 자동화 전용 크롬 창이 뜹니다.
  - 최초 로그인 시 구글 OTP 2차 인증이 뜨면, 뜬 크롬 창에서 직접 인증번호를
    입력해야 합니다(그 이후 당일에는 다시 묻지 않습니다).

■ 개인정보 관련
  - 아이디는 다음 실행 시 편하게 쓸 수 있도록 이 폴더의 credentials.local.json
    파일에 저장됩니다(비밀번호는 절대 저장하지 않습니다).
  - 실행 결과/기록은 이 폴더의 output/ 폴더 안에 쌓입니다. 다른 사람과
    이 폴더를 공유할 때는 output/, credentials.local.json은 제외하고
    전달하는 걸 권장합니다(개인정보가 들어있을 수 있음).

■ 문제가 있을 때
  - "run.bat"을 더블클릭하면 검은 콘솔 창이 같이 뜨는데, 오류가 나면 여기에
    에러 메시지가 표시됩니다(영어로 표시됨). 문제가 생기면 이 내용을 캡처해서
    알려주세요.
